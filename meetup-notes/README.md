# Meetup Notes

Notes from each AI Exchange session live here. The point: someone who could not attend can still get the thread.

## Filename convention

`YYYY-MM-DD-topic-shortname.md`

Examples:
- `2026-05-15-claude-skills-deep-dive.md`
- `2026-06-12-mcp-servers-show-and-tell.md`

## Template

Copy this into your new file and fill it in:

```markdown
# [Topic] — [Date]

**Date:** YYYY-MM-DD
**Format:** In-person / Online / Hybrid
**Attendees:** First names + GitHub handle (with consent), e.g. Chris (@chris1928a), Jane (@janedoe)
**Host:** Who ran the session

## TL;DR

Three sentences max. What the meetup was actually about, what the main takeaway was,
what is the most actionable thing for someone who missed it.
```

## What does NOT go here

- Client names or confidential project details (unless explicit consent)
- Personal attacks or political fights
- Marketing pitches for the host's own paid product (a brief mention is fine, a full slide deck is not)
